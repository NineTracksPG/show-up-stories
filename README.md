# Show Up Stories

Code repository for the Show Up Stories project.

Backlog, work items, sprints, and boards live in Azure DevOps:
https://dev.azure.com/NineTracks/Show%20Up%20Stories

- Work item hierarchy: Project > Workstream > Work (AU governance) and Epic > Feature > User Story (Agile), sharing the same backlog levels.
- RAID tracking: Risk, Action, Issue, Decision work item types.
- Status reporting: Project Status Report, Workstream Status Report.
- Sprints: fortnightly, under Release 1.
